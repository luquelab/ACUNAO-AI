
# Data

This folder contains the data used to test the model and potential references for the project.

## Table of Contents

- [Data Structure](#data-structure)
- [Data Sources](#data-sources)

## Data Structure

The `data` folder is organized as follows:

```
data/
│
├── 1_references/
│   ├── files        # References used  
│   ├── list_potential.md
│   ├── README.md
│
└── 2_test_data/
    ├── sample.pdf       # Documents used for testing  
    ├── vectordb   
    ├── processed_files.txt   
    ├── README.md   
```

### 1_references

- `data/1_references/files`: Contains reference sources files.   
- `data/1_references/list_potential.md`: Contains the list of current and potential reference sources.  
- `data/1_references/README.md`: Readme file for the folder.  

### 2_test_data

The folder contains the documents used to test the performance of the ACUNAO AI Assistant and the vector database that accompanies it. The contents of this folder will be the default database when ACUNAO AI Assistant is run and can be found under the `project_example` folder.
